# Verze 0.4.3

**Datum vydání:** 2026-05-07

## Záložka Performance

- **Nová záložka „Performance"** — V horní liště aplikace je dostupná samostatná záložka pro sledování výkonu backendu v reálném čase.
- **Živý monitoring přes SSE** — Tlačítko „Monitor performance" zapíná/vypíná live stream metrik (obnova cca každé 2 sekundy).
- **Přehledové karty metrik** — Okamžitě viditelné hodnoty: aktivní přihlášení uživatelé, requests/min, celkový počet requestů, HTTP 429/min, chyby 5xx/min, průměrná latence a in-flight requesty.
- **Časové grafy (sparklines)** — Grafy pro throughput, rate limiting (429), aktivní uživatele, latenci, CPU a RSS paměť.
- **Detail requestů** — Kliknutím na „Total requests" lze rozbalit tabulku posledních requestů (čas, metoda, endpoint, status, latence, userId) včetně průběžného refresh.
- **Runtime detaily procesu** — Event loop lag, heap/external memory, load average, aktivní performance streamy, HTTP status totals a uptime.

## Konfigurovatelné limity requestů

- **Limity jsou nově centralizované v `backend/config.json`** — Přidána sekce `requestLimits` pro snadné nastavení bez úprav kódu.
- **Nastavitelné položky**:
  - `requestLimits.jsonBodyLimit` (limit pro JSON body parser)
  - `requestLimits.auth.windowMs`, `requestLimits.auth.maxPerIp` (limity pro auth endpointy)
  - `requestLimits.api.windowMs`, `requestLimits.api.maxPerKey` (limity pro ostatní API)
- **Zachována kompatibilita s ENV** — Pokud jsou nastaveny příslušné ENV proměnné, mají přednost před hodnotami z `config.json`.
