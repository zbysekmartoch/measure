# Verze 0.4.0

**Datum vydání:** 2026-04-06

## Přejmenování záložek a terminologie

- **Záložka „Results" → „Debug"** — Záložka pro výsledky přejmenována na „Debug" s ikonou 🐞. Terminologie v celé aplikaci odpovídajícím způsobem upravena.
- **Záložka „Current output"** — Nyní zobrazuje obsah složky `Outputs` uvnitř laboratoře (dříve samostatná složka `current_output`).

## Spouštění workflow ze záložky Scripts

- **Tlačítko „Run workflow" ▶** — U souborů `.workflow` ve file browseru na záložce Scripts je nové zelené tlačítko pro přímé spuštění workflow. Výstup jde do složky `Outputs` v laboratoři (nikoli do číslovaného resultu). Ideální pro produkční běhy bez debuggeru.
- **Bez logových souborů** — Při spuštění ze záložky Scripts se nevytvářejí soubory `output.log`, `output.err` a `debuger.log` — ty slouží pouze pro ladění ze záložky Debug.

## Debug session pro jednotlivé skripty

- **„Create new debugging session" pro .py, .js, .cjs** — Tlačítko 🛠 pro vytvoření debug session se nyní zobrazuje nejen u souborů `.workflow`, ale i u `.py`, `.js` a `.cjs`. Po kliknutí se vytvoří debug session, jako by šlo o workflow obsahující jediný skript — bez nutnosti vytvářet `.workflow` soubor.
