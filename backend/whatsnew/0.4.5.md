# Verze 0.4.5

**Datum vydání:** 2026-05-18


## Settings: aktuální možnosti

V hlavním Settings jsou teď tyto volby:

- **Compact file buttons**
  - Zapnuto: tlačítka u souborů se zobrazují při najetí myší.
  - Vypnuto: tlačítka jsou vidět stále.
- **Enable double Shift keyboard menu trigger**
  - Zapnuto: klávesové menu otevřete i rychlým dvojitým stiskem Shift.
  - Vypnuto: menu se otevírá jen původním způsobem (double Escape).

## Klávesové menu: jak funguje a co umí

Klávesové menu otevřete takto:

- rychle 2x stisknete Escape
- nebo (pokud je to povolené v Settings) rychle 2x stisknete Shift

Po otevření se zobrazí poloprůhledné menu a stačí stisknout jednu klávesu:

- **C**: přepnutí na Scripts
- **D**: přepnutí na Debug
- **R**: přepnutí na Debug a spuštění Run pro vybranou session
- **V**: View, přepnutí mezi All a Focused zobrazením
- **X**: přepnutí na Chat
- **S**: Save All
- **U**: Unlock all

## Debug: Load Current Output Here

V záložce Debug je nově tlačítko **Load Current Output Here** (vedle tlačítek Run a Debug), které se zobrazí při vybrané session.

Co tlačítko udělá:

- zkopíruje aktuální obsah z **Outputs** (current output laboratoře) do vybrané session
- umožní rychle ladit nad aktuálním výstupem bez ručního kopírování souborů
- při shodném názvu souboru se obsah v cílové session přepíše

Typický postup:

1. Otevřete záložku Debug.
2. Vyberte session v poli Select session.
3. Klikněte na **Load Current Output Here**.
4. Pokračujte tlačítkem Run nebo Debug nad touto session.

## Focused režim

Focused režim je určený pro soustředěnou práci v laboratoři:

- skryje horní header aplikace
- skryje hlavní horní řadu záložek
- obsah začne hned záložkami laboratoře (Scripts, Debug, Chat, ...)

Výsledek: více místa na obrazovce pro editor a pracovní obsah.
