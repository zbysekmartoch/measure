# Verze 0.4.6

**Datum vydání:** 2026-05-29

## Runtime environment: nová logika tvorby běhové konfigurace

- **Nový runtime env soubor pro běh skriptů/workflow**:
  - Ze záložky **Scripts (Run)** se nově vytváří soubor vedle spouštěného souboru s příponou `.env`.
  - Příklady: `full_analysis.workflow.env`, `draw_plots.py.env`.
  - Pokud už existuje, vždy se přepíše.
- **Debug session**:
  - Při vytvoření debug session se ve výsledku vytváří `results/<id>/runtime.env`.
  - Tento soubor se používá při běhu session z Results/Debug.

## Kaskádové skládání `environment.json`

- Runtime env JSON vzniká **hlubokým merge** všech `environment.json` od kořene `backend/labs` směrem ke spouštěnému souboru.
- **Priorita**: čím blíže je `environment.json` ke spouštěnému souboru, tím vyšší má prioritu.
- **Pravidla merge**:
  - objekty se mergují rekurzivně,
  - skalární hodnoty se přepisují bližší vrstvou,
  - pole se nepřepisují, ale **concatenují**.

## Změna argumentů předávaných skriptům

Workflow runner nyní předává skriptům argumenty v pořadí:

1. `RESULT_ROOT`
2. `RUNTIME_ENV_PATH`
3. `LAB_ROOT`

Původní druhý argument (`WORKFLOW_ROOT`) byl nahrazen cestou na runtime env soubor.

## Report Builder (`build2.js`) aktualizace

- `build2.js` načítá konfiguraci z `RUNTIME_ENV_PATH` (argument 2).
- Pro ruční/legacy spuštění bez argumentu používá fallback:
  1. `RESULT_ROOT/runtime.env`
  2. `RESULT_ROOT/environment.json`
- Logy a hlášky byly aktualizovány na runtime env terminologii.

## Dokumentace

- Přidán nový dokument: `MEASURE_ENVIRONMENT.md`.
- Aktualizovány návody a API dokumentace pro nové runtime env chování (`scripts/run`, `scripts/debug`, Results debug běh, argumenty skriptů, struktura resultu).

## File Browser: seskupení souborů podle přípon

- **Nové seskupení souborů podle přípon**: ve File Browseru se soubory uvnitř složek zobrazují po skupinách podle přípony a uvnitř skupiny jsou seřazené podle názvu.
- **Výchozí stav je zapnuto**: seskupování je po otevření aktivní automaticky.
- **Rychlé zapnutí/vypnutí**: v horní liště File Browseru je vedle Refresh tlačítko `□`, kterým lze seskupování okamžitě přepnout.
- **Barevné odlišení skupin**: skupina má vlevo barevný pruh podle typu souborů (kategorie přípon), což usnadňuje orientaci v seznamu.
