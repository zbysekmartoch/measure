# Verze 0.4.4

**Datum vydání:** 2026-05-12

## Rozšířené formátování v Report builderu

- **Externí formátovací konfigurace** — Každý dokument v `report.doc[]` může používat vlastní soubor přes `format` (s volbou `formatInResult` pro hledání v `RESULT_ROOT`).
- **Pojmenované styly (`formatStyles`)** — Lze definovat reusable styly (např. `coef4`, `pValue`, `czDateTime`) a aplikovat je přes `use`.
- **Pravidla podle cesty (`format[]`)** — Formátování se aplikuje podle `path` včetně wildcardů `*` a `**`.
- **Skládání priorit** — Výsledné formátování se skládá z defaultů, stylů, inline pravidel a lokálních override parametrů v tagu.

## Number formátování

- **Podporované režimy (`number.mode`)**:
  - `number`
  - `percent`
  - `currency`
  - `scientific`
  - `star` (significance stars)
- **Significance stars (`star`)**:
  - `***` pro hodnoty >= 0 a < 0.01
  - `**` pro hodnoty >= 0 a < 0.05
  - `*` pro hodnoty >= 0 a < 0.1
- **Číselné parametry** — `minDecimals`, `maxDecimals`, `decimalSeparator`, `thousandSeparator`, `useGrouping`, `prefix`, `suffix`, `nullText`, `nanText`, `infinityText`, `multiplier`.

## Date formátování

- **Date styly (`date`)** — Formát přes `pattern`, `locale`, `zone`, `nullText`.
- **Podpora více vstupních formátů data**:
  - SQL datum/čas
  - ISO datum/čas (např. `2026-05-11T16:47:31.344Z`)
- **Připravené scénáře** — Bez problémů lze pokrýt:
  - anglické datumy
  - ISO výstupy
  - české krátké datumy
  - české dlouhé datumy (měsíc slovně)
  - datumy včetně času

## Lokální override v šabloně

- **Podporované klíče v tag parametrech**:
  - `format`
  - `use`
  - `number`
  - `date`
- **Použití stylu přímo v tagu** — Například `[[renderedAt {"use":"czDateTime"}]]`.

## Chování při chybách formátování

- **Bez pádu generování** — Chyby formátování neukončí celý render reportu.
- **Výchozí režim (`ignoreFormatErrors: false`)** — Do výstupu se vloží srozumitelný text `[FORMAT_ERROR ...]`.
- **Tichý režim (`ignoreFormatErrors: true`)** — Hodnota zůstane neformátovaná a chyba se zapíše do stderr.

## Globální proměnné dokumentu (`report.doc[N].globals`)

- **Globální hodnoty pro šablonu** — Lze dodat vlastní proměnné pro konkrétní dokument.
- **Priorita nad daty** — Pokud je požadovaná property v `globals`, vrátí se hodnota z `globals` i při kolizi se stejným klíčem v datech.
